SETUP
1. Put your original logo image in this same folder and name it exactly: logo.png
2. Open index.html in a browser to preview.
3. Replace the placeholder phone number (+910000000000), email, address and opening hours in index.html.
4. Food and restaurant photographs load from Unsplash, so an internet connection is needed to display them.
5. The reservation button currently calls a placeholder phone number. Replace it with your real restaurant number.
